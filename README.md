# 勤怠届 Webアプリ

パート従業員向け勤怠届フォームのWebアプリです。

## 機能

- 申請日の自動入力（今日の日付）
- 所管・氏名・社員番号の入力
- 区分の選択（11種類）
  - 有給休暇、欠勤、遅刻、早退、振替出勤、振替休暇、打刻忘れ、私用外出、打刻修正、勤務時間変更、その他
- 期間・日時の入力（年月日・時分・日数・時間数）
- 振替出勤日・振替休暇日の入力
- 事由の入力
- 印刷機能（ブラウザ印刷ダイアログ）
- リセット機能

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
